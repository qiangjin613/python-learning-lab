# python-learning-lab

一个用于系统学习 Python 的个人实验仓库，内容包括 Python 语法、算法练习、日常开发命令、常用库、小项目实践和零散知识沉淀。

## 一、项目目标
本项目用于记录和沉淀 Python 学习过程中的内容，主要目标包括：

1. 系统整理 Python 基础语法和常用特性。
2. 记录 LeetCode、算法题、数据结构题等练习过程。
3. 沉淀日常开发中常用的命令、工具和排查方法。
4. 通过小项目、小案例提升 Python 实际开发能力。
5. 存放学习过程中遇到的零散问题、笔记和总结。

## 二、目录结构

```
python-learning-lab
├── 01-python-basic             # Python 基础语法
├── 02-python-advanced          # Python 进阶语法
├── 03-algorithm                # 算法练习
├── 04-dev-commands             # 日常开发命令
├── 05-python-libraries         # 常用 Python 库
├── 06-practice-projects        # 小项目实践
├── 07-notes                    # 学习笔记与问题记录
└── 99-playground               # 临时代码区
```
